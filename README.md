# E-commerce Sales Dashboard

## Project Overview

The **E-commerce Sales Dashboard** is a data analytics project designed to analyze e-commerce sales data and convert raw information into meaningful business insights.

The dashboard provides a visual overview of sales performance and helps identify important trends and patterns through interactive charts, KPIs, and data visualizations.

The main objective of this project was to practice the complete process of **data preparation, analysis, visualization, and dashboard creation**.

---

## Objectives

* Analyze e-commerce sales data
* Understand overall sales performance
* Identify important sales trends and patterns
* Analyze product and category performance
* Create meaningful KPIs
* Build an easy-to-understand dashboard
* Practice data visualization and business analysis

## Key Business Questions

The dashboard was created to answer questions such as:

* What is the overall sales performance?
* Which products or categories generate the most sales?
* What sales trends can be identified?
* How does performance vary across different segments?
* Which areas contribute most to overall revenue?
* What patterns can be identified from the available sales data?

---

## Dashboard Features

### Sales Performance

The dashboard provides an overview of important sales metrics and helps understand the overall performance of the e-commerce business.

### Product & Category Analysis

Sales can be analyzed across different products and categories to identify strong and weak-performing areas.

### Trend Analysis

Visualizations help identify sales patterns and changes across the available time periods.

### Interactive Filtering

Slicers and interactive elements allow users to filter the dashboard and explore specific parts of the dataset.

### KPI Overview

Key metrics are presented at the top of the dashboard to provide a quick understanding of overall performance.

---

## Data Analysis Process

### 1. Data Collection

Started with raw e-commerce sales data containing relevant information about sales transactions, products, categories, and other available attributes.

### 2. Data Cleaning

* Checked the dataset for missing values
* Identified inconsistencies
* Reviewed data types
* Standardized relevant fields
* Prepared the dataset for analysis

### 3. Data Transformation

Used Excel formulas and calculated fields where required to prepare the data for analysis.

### 4. Exploratory Analysis

Used Pivot Tables to explore:

* Sales performance
* Product performance
* Category performance
* Trends
* Other relevant business metrics

### 5. Data Visualization

Converted the analyzed information into charts and visual elements to make patterns and insights easier to understand.

### 6. Dashboard Development

Combined KPIs, charts, tables, and slicers into a single dashboard for interactive analysis.
